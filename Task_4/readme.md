# Task 4 – HTML & CSS Units, Boxes and Fonts

This project demonstrates HTML structure styled with CSS which includes an Image and an Interactive button. Image size is adjusted using external CSS and the button is modified using external CSS, where a differnt font family is used, and also the image and button is adjusted to the point where it is not needed to be scrolled. All styling is managed in `style.css` linked to `index.html`.

## How to Run
Download the files and open `index.html` in any modern web browser (Chrome, Edge, Firefox, etc.). No server setup is required — this is an HTML-only assignment with external CSS.
