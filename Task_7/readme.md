# Task 5 – HTML & CSS Hero Section

This project demonstrates HTML structure styled with CSS which includes an Image and two Interactive buttons with using hover. This CSS task shows the  use of positions, float and display in context of the Hero Section. All styling is managed in `style.css` linked to `index.html`.

## How to Run
Download the files and open `index.html` in any modern web browser (Chrome, Edge, Firefox, etc.). No server setup is required — this is an HTML-only assignment with external CSS.
