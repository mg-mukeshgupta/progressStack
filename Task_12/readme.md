# Task 12 - JavaScript- Compound Interest Calculator

This is a project/task to create a simple compound interest calculator based on constant/scalar value given by the user which calculates and shows the compound interest after given certain years. Here, I have created two .js files which is linked to the main html file, to keep the code clean, and used the variables and formulas from the given task specification.

## How to Run
Download the files and open `index.html` in any modern web browser (Chrome, Edge, Firefox, etc.) and follow the instruction to show the example:
1. open the webpage using index.html.
2. right click anywhere on the webpage opened.
3. choose to INSPECT.
4. now select "CONSOLE" from the Dev tool Section (default will be ELEMENTS).
5. it will show the given example in the console tool.
