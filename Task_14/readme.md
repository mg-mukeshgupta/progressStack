# Task 14 - JavaScript- LOOPS

This is a project/task to create different functions using loop controls to get:
1. Table of a given variable number.
2. Check whether it is a Prime number or not.
3. Check if it is an Armstrong number or not.
4. Find all its factors and print/log them.
5. Sum of all the number upto the given Variable.

In this project, I have programmed all the functions using flow control loop and mathematical logics.

Download the files and open `index.html` in any modern web browser (Chrome, Edge, Firefox, etc.) and follow the instruction to show the example:
