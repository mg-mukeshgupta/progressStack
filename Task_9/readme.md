# Task 9 – HTML & CSS Transforms

This project was to demonstrate the use of transforms in webpages using CSS, so used the tansforms properties on a pseudo class HOVER on cta-btn named "Book a service today", which gets tilted whenver mouse is pointed over it and also increases in size. Also various chnages on width of the button is also made so it fit display for each resolution and media in good looking way ,i.e. for tablet and Mobile view.
All styling is managed in `style.css` linked to `index.html`.

## How to Run
Download the files and open `index.html` in any modern web browser (Chrome, Edge, Firefox, etc.). No server setup is required — this is an HTML-only assignment with external CSS.
