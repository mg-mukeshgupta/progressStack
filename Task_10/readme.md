# Task 10 – HTML & CSS Animations and Keyframes

This project demonstrates the use of different Transforms properties to create an Animation out of your basic css properties and styling.
Like using Translate to move any object like image along its X and Y axis with a clip of time used in animation, that creates an orbit like movement. Also scaling is used to create the squeezing like effect in the animation clip property. Also for correction in different view aspect the display property have been explicitly changed to flex for most of the container which helps in justifying objects and their alignment.
All styling is managed in `style.css` linked to `index.html`.

## How to Run
Download the files and open `index.html` in any modern web browser (Chrome, Edge, Firefox, etc.). No server setup is required — this is an HTML-only assignment with external CSS.
