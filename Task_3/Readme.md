# Task 3 – HTML & CSS Selectors

This project demonstrates HTML structure styled with CSS selectors. Headings are styled using classes and IDs, paragraphs are customized with tag and ID selectors, and lists are styled with pseudo-classes and attribute selectors. All styling is managed in `style.css` linked to `index.html`.

## How to Run
Download the files and open `index.html` in any modern web browser (Chrome, Edge, Firefox, etc.). No server setup is required — this is an HTML-only assignment with external CSS.
