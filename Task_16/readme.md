# Task 16 - JavaScript- Map and Filter

This is a project/task to create a HTML page which have information of different students in card format and can give result with search operatin based on their name or letter of their name.
Things Included in this task are:
1. HTML page with information of students.
2. Student information in card format.
3. A search bar which is stick to a place and only the cards are scrollable not the whole page.
4. A header with quotaion and Login button.
5. Search bar can help show the information of searched student by their Full name or first letter of their name DYNAMICALLY!

In this project, I have programmed all the function using array as input and used MAP and FILTER logic along woth some different other funvtion too, which are:
>getElementByID
>addEventListener
>toLowerCase
>querySelector
