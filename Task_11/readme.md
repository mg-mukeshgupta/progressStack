# Task 11 – HTML & CSS CSS MINI PROJECT

This is a mini project for css having 4 different pages, which were told to be the different sections in the task, but having different pages which works through navigation looks fine too, so this project includes:
1. Landing Page;
named as index.html file, in which the logo named "Thala 7." is used to navigate to the landing page, "Home" button will navigate to the landing page, in the Landing page.
2. Product Display;
named as product.html file, in which the Logo and the home button still works as the navigation to the home/landing page, this page also includes "Add to kart" button which navigate to the next page, by which the user can go to the next page name "Shopping Cart".
3. Shopping Cart;
named as shop.html file, in which home button navigates to the landing page, "continue shopping" link is used to go back to the product page and the "Pay Now" will make you proceed to the final page or section named as "Checkout", having razorpay logo to look legit.
4. Payment;
named as payment.html file, which as instructed on task is made having different payment methods, having razorpay logo to look legit, and on the left side having input for email and options for payment.
Different styling are made for each page , linked to their repsective html file, which are:
1. `index.html` styled with `style.css`.
2. `product.html` styled with `product.css`.
3. `shop.html` styled with `shop.css`.
4. `paymen.html` styled with `payment.css`.
## How to Run
All the images and logo png files are included in the folder of task 11.
Download the files and open `index.html` in any modern web browser (Chrome, Edge, Firefox, etc.) and navigate through given buttons specifications. No server setup is required — this is an HTML-only assignment with external CSS.
