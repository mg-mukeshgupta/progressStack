# Task 6 – HTML & CSS FLEX AND GRID

This project demonstrates HTML structure styled with CSS which shows a simple login page for laundry page having an image on the left and login setup on the right of the page. It show the use of flexbox and grid for positioning of the form and the login button. All styling is managed in `style.css` linked to `index.html`.

## How to Run
Download the files and open `index.html` in any modern web browser (Chrome, Edge, Firefox, etc.). No server setup is required — this is an HTML-only assignment with external CSS.
