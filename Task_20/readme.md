# Task 20 - JavaScript Mini Project
 In this project, I have created an interactive, responsive web application for browsing laundry services, managing a real-time shopping cart, and submitting booking requests with automatic email notifications via EmailJS, where user can:
 1. Add or remove items or services manually.
 2. Can navigate through sections of pages using links in header.
 3. A confirmation email will be sent to the customers mail address.

 In this project learn about how various event function in JavaScript helps creating a DOM and real-time interaction between user and webpage works, Here I have used:
1. querySelector() — Used to select HTML elements using their IDs and classes.
2.  addEventListener() — Used to respond to user actions such as clicking the Add Item, Skip Item, and Book Now buttons.
3.  textContent — Used to dynamically change the service name, price, and warning messages displayed on the webpage.
4.  .src — Used to dynamically change the service image according to the currently displayed service.
5.  push() — Used to add selected services into the cart array.
6.  forEach() — Used to loop through the cart and generate the bill/receipt rows dynamically.
7. How EmailJS works in this project with just using script linking format and how its other functions are being used here too.
8. how the trim() and Value functions are being used here in combinations to read and add input to the emailJS.


## How to Run
Download the files and open `index.html` in any modern web browser (Chrome, Edge, Firefox, etc.) and follow the instruction to show the example:
1. open the webpage using index.html.
2. Interact with the add and remove items buttons.
3. Use the book button to send the email confirmation to your mail address.
