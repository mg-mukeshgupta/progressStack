# Task 18 - JavaScript- DOM AND EVENT HANDLING

In this project , we have to create an user interactive webapage where the user can:
1. Interact with color boxes.
2. Input their name and can get result in real-time as greetings

In this project learn about how various event function in JavaScript helps creating a DOM and real-time interaction between user and webpage works, Here I have used:
1. getElementById : which returns element object of which Id is being used from the HTML
2. addEventListener : a function which activates when mentioned activity (like click here) is initiated
3. innerText : Used to render the text from a content of a node

## How to Run
Download the files and open `index.html` in any modern web browser (Chrome, Edge, Firefox, etc.) and follow the instruction to show the example:
1. open the webpage using index.html.
2. Interact with the block/ boxe named with color by clickiing on them.
3. Write or input your name on the "Enter Your Name" form input and click Greet Button
